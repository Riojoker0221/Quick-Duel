# Quick Duel

Quick Duel is a 2v2 turn-based strategy game.

Players ban one character and pick two characters to build a team.
Each character has unique skills, passive abilities, and resource mechanics.

## Current Version

Version 0.2

Version 0.2 begins with the release of Chimera.

## Game Modes

- Local PvP
- VS AI
- Online PvP

## Basic Rules

BP order:

A Ban → B Ban → A1 → B1 → B2 → A2

During battle, characters act in the order:

A1 → B1 → A2 → B2

Available actions include:

- Attack
- Defend
- Charge
- Heal
- Skill

The first team to defeat both opposing characters wins.
